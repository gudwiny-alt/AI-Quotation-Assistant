# 福建移动资金物流平台铺货报价工具

## 当前阶段

目前为“本地自动报价内测版”。它会在电脑本地读取当月的三份来源表：

1. 基础表；
2. 营销商品信息查询表；
3. BOP 资源信息表。

核心流程会先检查文件和必要字段，再按集团一级库物料编码关联数据。基础表 A
列每一条非空记录都会对应报价表中的一行；重复编码不会被合并，空白编码不会生成
报价行。

一次运行会依次完成三表关联、网站查价与截图；即使部分网站任务失败，也会生成两个互不覆盖的 Excel 文件：

- `YYYY年MM月终端供货价报价表.xlsx`：只保留“5G手机”工作表，沿用批准的表头、
  样式、滚动月份和公式；
- `YYYY年MM月报价执行报告.xlsx`：包含“运行总览”和“处理明细”，可按品牌、
  产品经理和渠道定位待处理项目。

如果同名文件已经存在，程序会自动使用带时间的安全文件名，不会覆盖原文件。输入
文件和报价模板也不会被修改。

## 结果如何理解

- “完成”：三张本地表以及京东、天猫、品牌官网三个渠道均已完成；
- “部分完成”：三张本地表已经完成可用关联，但部分网站价格、链接或截图仍待补充；
- “失败”：本地来源中存在会影响可靠关联的问题，例如营销记录缺失或冲突；
- “不支持”：品牌不在首版明确支持的七个品牌内，报价行仍会保留；
- “待人工补充”：存在网站技术失败、登录等待、字段不完整或不支持品牌时，需要人工补充 AI:AN。

报告中的总行数等于“完成 + 部分完成 + 失败 + 不支持”；品牌和产品经理汇总也与
处理明细逐行对账。

## 使用方式

1. 打开程序，选择基础表、营销商品信息查询表、BOP资源信息表和输出文件夹；
2. 默认报价年月为当前自然月，可按需修改；
3. 点击“开始自动报价”。首次使用时，程序会打开专用 Chrome 窗口；如网站要求登录，产品经理仅在该浏览器内自行登录一次；
4. 登录状态保存在当前电脑的用户资料目录，后续运行会自动复用；
5. 完成后打开报价表和执行报告。报告会汇总总行数、完成、部分完成、失败、不支持品牌和待人工补充行。

Mac 测试版保留整屏截图并以缩略图嵌入 Excel；Windows 正式版将按截图示例进行严格验收。程序不收集密码，也不上传来源表、报价结果、截图或浏览器登录状态。
