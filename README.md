# 福建移动资金物流平台铺货报价工具

## 当前阶段

目前完成的是“本地核心验证版”。它会在电脑本地读取当月的三份来源表：

1. 基础表；
2. 营销商品信息查询表；
3. BOP 资源信息表。

核心流程会先检查文件和必要字段，再按集团一级库物料编码关联数据。基础表 A
列每一条非空记录都会对应报价表中的一行；重复编码不会被合并，空白编码不会生成
报价行。

一次成功的核心运行会生成两个互不覆盖的 Excel 文件：

- `YYYY年MM月终端供货价报价表.xlsx`：只保留“5G手机”工作表，沿用批准的表头、
  样式、滚动月份和公式；
- `YYYY年MM月报价执行报告.xlsx`：包含“运行总览”和“处理明细”，可按品牌、
  产品经理和渠道定位待处理项目。

如果同名文件已经存在，程序会自动使用带时间的安全文件名，不会覆盖原文件。输入
文件和报价模板也不会被修改。

## 结果如何理解

- “部分完成”：三张本地表已经完成可用关联，但网站价格、链接或截图仍待补充；
- “失败”：本地来源中存在会影响可靠关联的问题，例如营销记录缺失或冲突；
- “不支持”：品牌不在首版明确支持的七个品牌内，报价行仍会保留；
- “待人工补充”：当前核心版尚未处理 AI:AN 的网站价格、链接和截图。

报告中的总行数等于“完成 + 部分完成 + 失败 + 不支持”；品牌和产品经理汇总也与
处理明细逐行对账。

## 尚未包含的功能

当前版本还不是产品经理可直接点击使用的正式程序。京东、天猫和品牌官网的自动
查询、登录状态复用、截图，以及最终的 Mac/Windows 图形界面将在后续阶段实现。
在这些功能完成前，AI:AN 会保持空白，并在执行报告中明确标为待人工补充，不会
被误报为处理成功。

所有处理均按“完全本地”方案设计；核心版不会上传三张来源表或报价结果。
