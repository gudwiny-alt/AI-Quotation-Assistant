# 写回状态与截图补救

2026-09-14；基于 e002293 开发。

## 报价保存与确认

- 五项金额和备注与报价表实际单元格一致时，当前商品第三步显示蓝色“已写回报价表”。预览行同时显示本批次已写回数量。
- 再修改金额或备注会回到“待写回”；恢复为已保存的数值时恢复已写回。金额格式 2090 与 2090.00 视为相同。
- “已写回”表示数据已经保存；“确认本品报价”表示报价规则通过并确认当前报价。最终报送还需要稽核通过。
- 连续确认多款商品会保留此前仍有效的确认。正常人工稽核不清空报价确认；价格、资格或截图变更后，需要重新核验受影响商品。

## 补充或替换真实截图

两个入口共用同一功能：

1. 报价决策智能辅助 → 查看取价证据 → 补充／替换截图。
2. 稽核审查工作台 → 选择商品和渠道 → 补充／替换截图。

选择官网、天猫或京东，选择真实 PNG/JPEG 页面截图，核对预览中的商品、规格、店铺和价格，填写处理说明后保存。建议提供原始全分辨率、无遮挡的页面截图。

保存会只更新当前商品对应渠道的 Excel 图片，并在“截图证据/人工补充”保存原分辨率文件。报价金额、其他单元格、公式和其他图片保持不变。之前版本保留在历史备份和处理记录中。

新图会重新进行本地识别及内容稽核；原图的人工结论不会自动套用到新图。若新图显示的价格与当前取价不同，请重新取价并进行报价试算，不能只换图片就把新价格当成已核验。确定性的登录页、权限弹窗等问题仍不能人工放行。

目前荣耀官网被权限弹窗遮挡、荣耀天猫缺图的历史记录不会被本次升级自动改成成功。需先取得真实的新截图，再使用上述入口处理。

## 稽核人及最终报送

在稽核工作台底部“设置本批次稽核人”填写一次，人工复核自动沿用。也可在首次人工复核时填写，程序将其设为本批次默认；后续在某个商品复核时修改姓名，会作为该商品的覆盖值。每项仍需选择通过或未通过并填写理由，时间自动记录。更换默认姓名不会修改历史记录中的签名。

有未通过、待处理或未检查事项时，只能导出草稿。所有适用稽核点完成后，还需各款当前报价已确认，才能确认最终报送版。

## 备份

.bak 是报价表修改前的完整副本，不是可随意丢弃的临时文件。新备份集中在输出目录下“历史备份”，同样金额反复保存或确认不会重复改写 Excel、生成备份。原来输出目录中的旧 .bak 不会被自动删除或移动。

本轮验证没有修改用户正式报价表、截图或数据库，也没有重新运行真实网站采集。
