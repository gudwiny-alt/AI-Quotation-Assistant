# AI 智能总结

软件总名称改为“报价协同智能体”，三个业务智能体保持原名。导航中的“AI 智能总结”独立展示本批次综合判断、最多三项管理建议，以及批次总结、价格情报理解、报价方案推理、稽核异常分析四类建议。

## 使用

在“系统设置 → AI 模型服务”或“AI 智能总结 → 模型设置”中填写服务地址、模型名称和 API Key。接口采用兼容 Chat Completions 的 `/chat/completions` 协议。服务地址填写 Base URL，不要重复填写接口路径。

调用信息保存在原应用数据目录的 `ai-settings.json`，采用本机所有者读写权限及原子保存。代码和安装包均不携带公司地址、模型名称或 Key。复制 App 到其他电脑需要在当地重新配置。该文件属于本机私有配置，并非加密保险库。

先完成报价或打开已生成的报价表，再点击“生成分析”。只在这次明确操作时向设置的服务发送当前批次文字快照，不自动上传、不发送截图原图。快照包含价格、既有程序精确计算结果、渠道结果、稽核摘要、有效人工复核理由与已知缺项，过滤常见本机路径并排除复核人身份。原有报价、截图、写回和确认逻辑保持独立。

AI 仅产生建议，不执行工具、不改价格、不写 Excel、不替代产品经理确认，也不改变稽核结论。“展开全文”和“查看依据”仅阅读。查看依据可了解对应商品、渠道、规则与检查结果，以及生成时间、模型、耗时和服务返回的用量。

生成期间可切换页面。后台线程只接收普通数据，不持有 Tk 控件或业务对象。分析使用点击时的快照；报价或证据变化后显示旧快照提示，重新生成后才对应当前数据。建议暂存在本次 App 内存中，退出后需重新生成，不写入业务复核记录。

接口失败显示简短错误，可修正设置后重试。超时、重定向、超大响应、格式不符、工具调用、来源编号不存在或快照编号不符均不会被当成有效分析。当前接入以兼容协议实现，并已使用本机配置的公司服务完成真实调用验证。网络响应等待上限为300秒，页面显示实际等待时间；请求启用JSON输出模式。其他服务仍需验证兼容性。

## 验证边界

基线：82c4824。新增模块以只读服务和独立页面方式接入；保留原应用数据目录、浏览器资料及 bundle identifier。

原生测试使用明确标注的测试响应，仅用于截图和交互验证，未作为软件默认结果，也未向外部模型上传真实数据。包括空状态、成功响应、错误处理、Key 掩码、过期快照、窄窗口滚动及原业务页面导航。公司调用信息单独预填到用户本机数据目录，不进入 Git。

本机 WindowServer 对窗口高度限制约为 840 像素。既有原生布局回归的四项窗口高度/日志断言仍失败，与基线版本已记录的四项一致；没有修改原有断言掩盖问题。新 AI 页面窄窗口和正常宽度测试通过。
