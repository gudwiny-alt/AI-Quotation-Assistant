## 本轮已完成的可自动验证部分

- Retina 2× 坐标换算单元测试；
- mss 只使用主屏的 Quartz 逻辑矩形（例如 1440×900），不把
  2880×1800 物理像素边界误传给 Quartz；在串行锁内临时关闭
  `IMAGE_OPTIONS` 缩放并在退出时恢复；
- CSS viewport 坐标到整屏物理像素坐标的边界检查；
- 整个主屏 PNG 的临时文件、质量校验、红框和原子发布流程；
- 截图尺寸与 `CGDisplayPixelsWide/High` 不一致，或
  物理尺寸÷mss 逻辑尺寸与快照 scale / JavaScript DPR 不一致时，按
  `CAPTURE_GEOMETRY` 失败关闭，避免猜测 mss 的 Retina 缩放；
- macOS 平台专属能力惰性加载，未授权时返回
  `CAPTURE_PERMISSION`，不会发布正式证据。

## 真实冒烟测试前置条件

1. 在“系统设置 → 隐私与安全性 → 屏幕与系统音频录制”中，为实际运行程序授权；
2. 由后续浏览器运行器提供并校验：
   - 受管 Chrome 窗口的最大化/前台控制回调；
   - 当前前台窗口标识；
   - 同一次采样绑定的浏览器标识、主屏物理边界、浏览器物理边界；
   - Playwright/CDP 页面 viewport 原点、CSS 宽高、DPR、缩放和
     原生窗口边界的校准结果；
   - 浏览器已最大化、非全屏的权威状态；
   - 菜单栏日期时间与 Dock 当次可见的权威证明提供器。仅读取
     “自动隐藏”偏好不足以构成证明，未提供时必须失败关闭；
3. 打开一个受管 Chrome 页面，并保持菜单栏日期时间和 Dock 可见。

这些值不能用原生顶层窗口或 client-area 原点代替。标签栏和地址栏也位于浏览器
client 区，直接使用该原点会导致网页 DOM 红框整体偏移。

## 待执行验收项

- 截图包含标签栏、地址栏、网页、菜单栏日期时间和 Dock；
- 实际文件尺寸与主屏物理像素尺寸一致；
- DOM 目标红框在 Retina 缩放下准确对齐；
- 截图前后切换其他应用时返回 `CAPTURE_OBSCURED`；
- 空白、黑屏、低对比或不稳定页面不会发布正式证据；
- 记录实际分辨率、缩放、截图路径和验收结论。

自动质量门只检查尺寸、空白、对比度、熵、清晰度和页面稳定性；截图中文字是否
足以供业务人员阅读仍是人工冒烟验收项，不宣称由这些数值指标自动证明。

缺少 mss 等固定截图依赖时返回非重试 `CAPTURE_ENVIRONMENT`；普通临时 PNG
写入权限错误属于 `CAPTURE_FAILED`，只有原生屏幕 API 明确拒绝读取屏幕像素时
才使用 `CAPTURE_PERMISSION`。
