# Mac .170 UI 预览版验证记录

基线：94aaecb。实现：ad2f1a9。布局修复及预览标识：20e9efb。分支：codex/mac-170-ui-refresh。

## 变更

保留 Tkinter/ttk 与 .170 执行核心，增加蓝白侧栏工作台：协同总览/数据准备、价格情报、报价决策、稽核审查、任务记录、系统设置。窗口、侧栏明确标记 UI预览版。

来源文件用卡片、简短文件名与完整路径详情展示。继续使用手工 Excel 导入；没有 BOSS 自动直采。运行界面消费真实事件及最终结果，不生成模拟业务数据。历史使用只读 SQLite，避免触发任务恢复写操作。报价页显示已有工作簿价格/公式结果，不添加毛利或审批规则。已保存价格、截图状态和技术失败分开显示。

默认1280×850，最小1000×720。总览和设置增加纵向滚动；常驻开始/继续/取消/输出操作及执行日志。真实站点交互、报价公式、Excel处理、截图引擎、任务恢复写逻辑未改。

## 仍需验证的边界

桌面工具按完整App路径读取窗口反复超时，bundle id也被历史同名包共用。新包已启动，进程采样显示处于正常Tk事件循环；没有取得可供视觉验收的真实窗口截图。几何测试不能替代像素级视觉验收，尤其尚未验证大量真实数据填充后的视觉密度。

本次未启动真实网站批量取价，未做新包的Chrome前台取证实测。因此交付为UI预览版，尚不能作为替代.170稳定版的批量生产验收结论。

WorkerEvent不含全部计划任务数/完整规格/截图路径时，UI显示已收到的记录和可读取的保存明细，不编造总量。决策页等待实际FullPipelineResult；增量价格仍可在情报页和原有工作簿中查看。全部缓存且没有新事件的运行可查看真实报价行，渠道明细从任务记录查看，不猜测最新run_id。稽核页显示保存证据及异常状态，不宣称新执行了完整哈希审计。
