## 本轮定点修复

1. 京东商品详情页：四项已经同屏时保持当前画面；标题刚好位于画面上方时，只在当前滚动区域内小幅、有限次向上修正，找到第一张合法画面后立即停止。
2. 京东无报价搜索页：从 80% 开始逐级缩小，直到搜索词与完整结果区域同时进入画面；重试时从当前缩放继续，不再反复放大、缩小。
3. 小米官网：兼容当前 `/shop/buy/detail?...product_id=...` 商品入口。
4. 华为官网：搜索结果没有旧版商品卡外层标记时，允许从与目标机型名称完全一致的可见商品文字进入；详情地址仍须通过华为商城数字商品页校验。
5. 天猫继续沿用原有容量定位与截图行为；本轮京东截图规则不会再改变天猫页面。
