## 本轮定点修复

1. 修复 OPPO、vivo、小米京东无精确机型页面在正式截图阶段因搜索框临时变空而无法截图的问题。
2. 仅当当前京东店铺搜索网址已经证明本次搜索、结果区仍有效且没有精确机型时，程序才把本次机型名称恢复到可见搜索框；该动作不提交搜索、不刷新页面，也不改变搜索结果。
3. 搜索框不可见，或搜索框出现其他机型名称时，程序仍拒绝截图，避免产生错误证据。
4. 未修改京东苹果详情页、天猫、品牌官网和 Excel 输出逻辑。
