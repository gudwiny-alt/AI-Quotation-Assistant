## 修复范围

- 华为官网接受已观察到的网络制式尾部及颜色名称，同时保留基本型号和 Pro、Ultra、SE 等衍生型号边界。
- 按用户确认的业务口径，天猫华为官方旗舰店与京东华为自营官方店未标 RAM 时，可以匹配 ROM；明确 RAM 的容量选项或选中后的商品标题仍须一致。其他品牌不套用此例外。
- 稽核同步使用来源表中的品牌信息。ROM-only 例外要求官方店铺、型号、ROM 和颜色证据一致；显式 RAM、RAM+ROM 简写或 RAM 标签不按“未标 RAM”自动放行。规则版本更新，旧确认可能需要按新规则重新确认。
- 天猫颜色匹配去除已观察到的“万人加购／店长主推”尾部，不放宽颜色本身；识别 data-disabled=true，沿原颜色／容量不可用流程处理。
- 京东不再将 nova 16 SE 当作 nova 16 候选；截图前检查店铺标识、标题、价格和选中规格同时在视口内，最多六次小幅上移，仍无法完整显示则保留失败，不伪造店铺证据。
