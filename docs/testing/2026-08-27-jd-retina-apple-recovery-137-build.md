## 本轮定点修复

1. 仅在 macOS 正式整屏视觉复核模式下，按 CDP 与 `CGWindow`
   共同使用的逻辑屏幕坐标绑定 Chrome 窗口；Retina 设备渲染比例保持为 2，
   3840×2160 正式截图规则不变。
2. 仅对京东苹果处理同一颜色/容量同时出现在包装容器和可点击按钮上的情况；
   只有存在唯一可操作叶节时才优先它，其他品牌的严格唯一性判定不变。
3. 无货文字本身不再导致父子重复节点被判为容量/颜色歧义；仍必须确认
   目标配置真正处于选中状态后才取价和截图。
4. 未修改品牌官网、天猫、Excel 输出和其他品牌的业务逻辑。
