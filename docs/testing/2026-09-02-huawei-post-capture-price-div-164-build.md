## 问题原因

华为官网截图中已经清楚显示 `¥2199`，但该价格在页面中可能由没有稳定 class 或 data-testid 的普通叶子 `div` 渲染。旧逻辑没有把这类节点纳入候选；同时，价格所在较大父区域可能包含“补贴、分期”等文案，导致合法主价格被宽泛的上下文排除条件误伤。

## 修复范围

- 华为官网截图成功后，允许读取文本为精确货币格式的可见叶子 `div`。
- 仍通过当前节点及祖先节点的 class 排除补贴、优惠券、分期、划线价等促销价格。
- 保留“截图优先、截图成功后不回滚”的既有闭环；价格后置读取失败也不得删除截图。
- 未修改京东、天猫及其他品牌官网的生产逻辑。
