# .175：vivo 新标签页导航时序修复与天猫截图复核

## 用户实际失败

批次 f04a77a2-c965-4f58-9c58-cdd72461d844（2026-09-19 17:48）：

- vivo Y50s 官网三次 LAYOUT_CHANGED，无取价检查点。
- 同商品天猫已有“未找到型号”的观察检查点，失败发生在正式截图上下文构建，错误为 CAPTURE_ENVIRONMENT。

## 根因与范围

用正式程序相同的 NativeChromeCdpSession、专用官网配置和 MacFormalCaptureRuntime 启动参数，成功复现 vivo 失败：点击新搜索卡片后，CDP 已报告新标签页，但其 URL 暂时为空字符串。原实现只等待 about:blank，空字符串被立即判为非法商品地址。

本次生产行为仅修改 vivo 该判断：空字符串和 about:blank 均在原有有界等待窗口内等待首个真实地址。真实地址继续严格校验官网域名与数字商品路径，超时仍失败，错误型号、规格及颜色仍拒绝。其他品牌、天猫、京东、通用截图和业务规则没有改动。另更新 .175 版本标识。

.174 的临时浏览器验证未触发该时序，且未覆盖正式系统截图，不能据此认定真实任务完整修复。本次补齐正式配置复现和系统截图验证。
