# vivo 官网搜索兼容修复（2026.09.19.174）

## 范围

基于 582477b（.173），业务代码仅修改 vivo 官网适配器。其他品牌官网、天猫、京东、报价规则、稽核、恢复和导出逻辑均保持不变。另更新版本标识与对应测试。

## 原因与处理

最新批次 `c7fe2bf9-3426-4575-9c40-6f07e2ffbff7` 的 vivo Y50s（6GB+256GB／钻黑）在官网入口连续遇到 LAYOUT_CHANGED。新版官网搜索输入框改为点击后加载，结果路径由 `/search/searchResult` 改为 `/search/result`，商品卡片通过新标签页跳转而非直接提供链接。详情页标题还存在异步加载延迟。

- 保留原搜索框、路径、卡片与链接处理，兼容新版入口和商品卡片。
- 在搜索控件、导航和详情标题加载期间有界等待。
- 无链接卡片只接受 vivo 商城数字商品路径，随后在受控页面重新核验详情。
- 继续严格核对型号、容量、颜色和稳定价格，不采用搜索卡片起售价。
- 只有推荐商品、没有可靠无结果标志时仍报技术失败，避免误判“无此型号”。

- 联合回归：839 项通过（25.54 秒），覆盖 vivo／华为官网、天猫、京东、截图视图、渠道稽核、补充修正、应用和重启恢复等。
- vivo 修改文件 Ruff 检查及 git diff --check 通过。
- 独立代码审查未发现阻塞问题。
- 官网实测 Y50s：正确匹配 6GB+256GB／钻黑，详情价 1799.00 元；截图准备后的语义复核一致。浏览器诊断截图包含型号、价格、容量、颜色。
- 实测使用临时浏览器，原任务数据库只读，未改写业务任务、报价工作簿和历史截图。没有重新执行整批报价；此次诊断截图并非正式任务的系统屏幕截图验收。

## 已知边界

新版网站无结果页面的终态结构尚未确认，未知布局继续按技术失败处理。弹窗点击自身抛异常时，依靠任务运行器统一清理浏览器。此次修复不扩大采价规则或变更缺货判断口径。
