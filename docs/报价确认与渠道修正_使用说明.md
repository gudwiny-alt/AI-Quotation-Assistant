# 报价确认与渠道修正

本版接续 04b3b37。退出旧 App 后，打开新版，再在报价决策或稽核页面打开已生成的报价表。现有金额可继续使用，无需重新运行整批采集。

## 两个按钮

- **保存并写回报价表**：把填写内容保存到 Excel；规则尚未全部通过也可以保存草稿。保存成功后步骤显示“已写回报价表”。保存不等于产品经理已确认。
- **确认报价并提交稽核**：报价规则通过后，保存并记录本品确认状态，交给稽核工作台完成最终复核；此按钮不代表整批最终报送已经通过。

商品列表与单品页顶部持续显示“未确认／已确认／修改后待重新确认”。修改价格、说明、资格依据或渠道证据后，受影响商品需要重新确认。确认记录保存于报价表旁的 `.review.json`，稽核报告也体现确认状态；不为此新增 Excel 列或工作表。

旧版本确认采用的依据字段与本版不同，打开旧批次时可能显示“修改后待重新确认”；核对本版规则后重新确认即可。

## 说明与图片写入位置

- 报价说明文字 → **AP：超6个月价格说明**。
- “添加依据图片（AO）”中的 PNG/JPEG → **AO 的实际嵌入图片**，支持多张，并可随 Excel 一起交付。
- 下方写回预览同时列出 K/L/M/P/Q 金额、AP 说明、AO 图片数量。点击保存后才写入 Excel。

旧版复核记录中可识别的 AO 文字说明会迁入 AP；不擅自删除原表的 AO 内容。AO 目标位置如果存在图表等非图片对象，程序会提示并取消保存，避免破坏原文件。

## 补充修正渠道取价

入口一：**报价决策智能辅助 → 查看取价证据 → 补充修正渠道取价**。

入口二：**稽核审查工作台 → 选择商品 → 补充修正渠道取价**。

在同一窗口选择官网／天猫／京东，检查或替换真实商品截图，填写渠道价格、商品来源完整链接、处理说明，然后保存。

程序将同步更新对应渠道的截图、价格及价格单元格超链接，重新计算三网最低价和最低价来源，并刷新决策与稽核数据。该记录显示“人工补充”；原截图和修改历史保留。价格或证据变化后，本品需要重新确认。

例如华为官网已补图但仍缺价格和链接，可以直接使用已有截图补齐这两个字段；无需到 Excel 中手工拼接，也无需重跑其他已成功渠道。链接请从真实商品页复制，截图本身不一定包含完整网址。

新操作不能自动证明证据符合全部规则。截图存在遮挡、来源或价格不符时，会继续提示处理；完成相应检查后才可确认最终报送版。

## 文件与验证范围

保存前的完整备份继续进入“历史备份”；原有备份保留。交接整个可继续处理的批次时，请保留报价表、同名 `.review.json` 及相关证据目录。

华为官网修正针对商品卡片打开新标签后的等待时序。已实际验证目标商品、规格选择及取价；本轮未重新执行完整的官网／天猫／京东正式截图报价批次，也未继续调查此前暂停排查的偶发 App 退出问题。
