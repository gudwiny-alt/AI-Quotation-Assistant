# 报价决策与稽核增强版

基于已验证 Mac 界面分支 `724820d` 开发。保留原取价、截图和自动生成报价工作簿流程，新模块在工作簿生成后提供本地填写、提示、写回和稽核。

## 如何进入

1. 照原来的方式完成自动报价，点击左侧“报价决策智能体”。也可点击“打开已有报价表”，选本机已生成的工作簿并核对报价月份，无需再次取价。
2. 在商品清单点“填写与试算”，进入“报价决策智能辅助”。填写采购价、全国均价、买断价、零售价和当月报价，右侧提示随输入更新。切页或切换商品会保留本次会话中尚未保存的输入；关闭软件前请保存草稿。
3. “补充资格与日期依据”用于已核实的分类、在库状态、入库日期及首次报价日期，需要填写依据说明。超过14个月的商品确认属于优福包后记录为不报价；未确认时保留待复核。
4. “保存草稿并写回报价表”只写入对应商品的 K/L/M/P/Q/AO。有规则未通过也能保存草稿，不能据此标记为通过。保存前自动备份，原有 N 货源、自动字段、公式、图片和其他工作表保留。
5. 左侧“稽核审查智能体”进入“稽核审查工作台”。顶部和六类卡片是全批次统计；选择商品后右侧展示其检查集合，再点检查项查看对照、原因、证据和处理入口。
6. 可人工复核的疑点需要理由及操作人；精确超限等确定性失败不可人工覆盖。导出稽核报告生成独立本地 HTML，浏览器可打开和打印，不会上传外部系统。

## 本版已经可计算的规则

- 采购价与全国均价比较：L≤M，不能误用K与M比较。
- 手机加价上限：K≤L×1.045，按精确十进制判断；2090.0001/2000不能因为显示四舍五入而通过。
- 已知上一期、分销零售价、一级库价等已知上限比较；渠道原始价格的有效性单独核验。
- 人工提供依据的分类、在库与时间资格；超14个月先确认优福包，再记录不报价。
- 工作簿正确行与字段、截图文件有效性、报价写回一致性和版本变更检查。

## 需要继续明确的口径

历史报价的全量范围、周期调价基准、超过12个月的算法、优惠价接受条件、截图有效期限和不报价在最终表内的正式表达尚未形成完整定义。本版不自行假定这些规则已经满足，对应检查保留待复核。因此当前可以完成填写、试算、草稿写回和稽核草稿导出，尚不能把整批数据标为最终报送通过。

截图文件能打开不代表其规格、价格和店铺内容已经通过；内容检查由带依据的人工复核完成，本次没有新增外部图像识别服务。

## 文件与保护

- 原工作簿旁保存 `.review.json`，记录资格依据、精确商品与渠道关联、源异常、复核历史及文件版本；与工作簿一起保留。旧表没有来源记录时会如实显示缺失。
- 每次手工写回在同目录创建带时间戳的 `.bak`。工作簿被 Excel 或其他程序改动后，本版拒绝覆盖，需重新打开核验。
- 修改价格、依据或证据后旧复核会失效；完成新检查之前不会继续使用旧结论。
- 依据附件按本地文件路径关联，请保留原文件。附件变化或缺失会影响核验状态。
- 原取价失败与待补截图仍通过价格情报页面处理。浏览报价或稽核页面不会启动采集。

## 验证说明

使用临时工作簿与隔离原生窗口测试手工写回、备份、错行拒写、文件保真、精度边界、异常恢复、跨页草稿和稽核筛选。真实网站取价沿用此前已验证流程；本次没有为界面验证重新运行整批网站采集。
