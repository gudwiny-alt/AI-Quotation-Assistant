# OPPO 已选配置与二维码遮挡修复设计

**日期：** 2026-08-12
**状态：** 用户已确认
**范围：** 仅 OPPO（欧珀）品牌官网；不修改荣耀、小米、京东、天猫、Excel 或其他品牌官网。

## 1. 现场证据与根因

`.67` 真机测试结果：

- OPPO A6t 取价和截图成功；
- OPPO A5m 连续三次在价格检查点保存之前以 `LAYOUT_CHANGED` 失败；
- A5m 详情页的目标容量 `8GB+256GB` 已经处于选中状态，但右下角固定二维码浮层遮挡了该按钮区域。

当前实现发现目标容量后无条件再次点击。A5m 的目标按钮被二维码覆盖时，点击可能被浮层拦截；A6t 的目标按钮未被覆盖，因此同一逻辑可以成功。正式截图的现有几何判断只校验四个元素位于视口内，没有验证元素中心点是否被固定浮层遮挡。

## 2. 目标与非目标

### 2.1 目标

1. 目标容量或颜色已经唯一且正确选中时，不再重复点击。
2. 未选中时仍按既有规则点击目标选项，并等待唯一选中状态稳定。
3. 正式截图要求标题、当前价格、目标颜色和目标容量都在视口内，并且关键证据没有被固定二维码遮挡。
4. 若仅因二维码遮挡或四项未同屏，最多执行一次轻微定向滚动，再重新定位和复核四项证据。
5. 保持 A6t 已成功流程与 `.67` 的 80% 缩放生命周期。

### 2.2 非目标

- 不放宽机型、容量、颜色或价格语义匹配。
- 不把被二维码遮住、无法人工辨认的容量当作合格截图。
- 不隐藏、删除或修改网站二维码 DOM。
- 不增加反复上下滚动。
- 不修改搜索结果卡、缺货卡、5G 归一化、Excel 写入或其他网站逻辑。

## 3. 方案选择

采用“已选项短路 + 遮挡感知的一次定位”方案。

### 3.1 已选项短路

处理每个配置组时：

1. 定位唯一精确目标选项；
2. 若它已经是该组唯一选中项，直接进入下一步；
3. 若尚未选中，才执行一次点击；
4. 点击后继续使用现有的唯一选中稳定等待。

这从源头避免点击被二维码覆盖的已选容量，同时不改变未选配置的行为。

### 3.2 截图遮挡判断

正式截图在 80% 下获取标题、价格、容量、颜色四个定位元素。每项必须：

- 可见且有非零矩形；
- 完全位于当前视口；
- 元素中心点的最上层页面元素仍是该证据自身或其子孙节点。

最后一项使用页面命中测试判断固定浮层是否覆盖证据，不依赖二维码的易变 class 名称。

### 3.3 一次轻微定位

若首次检查未通过：

1. 根据四项联合矩形计算满足同屏的最小纵向移动；
2. 优先将容量证据移动到二维码上边缘之外，同时保留标题和价格；
3. 只执行一次即时滚动；
4. 等待短暂布局稳定后重新获取四项元素；
5. 四项均在视口且未被遮挡则截图，否则封闭失败。

不允许循环寻找位置，也不允许滚动后继续使用旧矩形。

## 4. 完整处理流程

```text
进入合法 OPPO 详情页
  → 幂等切至 80%
  → 校验标题
  → 定位目标容量
      → 已唯一选中：不点击
      → 未选中：点击并等待稳定
  → 定位目标颜色
      → 已唯一选中：不点击
      → 未选中：点击并等待稳定
  → 等待报价稳定
  → 恢复业务识别前缩放
  → 保存价格检查点
  → 正式截图前幂等切至 80%
  → 四项同屏且未被遮挡：直接截图
  → 否则轻微定位一次，再复核并截图或封闭失败
  → 恢复截图前缩放
```

## 5. 错误处理

- 精确容量或颜色不存在、重复或不可用：沿用现有合法“无”或结构失败规则。
- 精确目标已经选中：不得因浮层阻挡重复点击而失败。
- 未选目标的必要点击确实被阻挡：继续作为技术失败，不伪造选中状态。
- 一次轻微滚动后四项仍不同屏或仍被遮挡：不截图，保留已保存的价格检查点。
- 缩放、定位或恢复失败：沿用现有技术失败及恢复机制。

## 6. 测试与回归保护

新增契约至少覆盖：

1. A5m 目标容量预先选中且被浮层覆盖时，不执行容量点击，仍可取价。
2. 目标颜色预先选中时同样不重复点击。
3. 目标未选中时仍执行点击并等待稳定。
4. 四项位于视口但容量中心点被浮层覆盖时，首次截图检查不通过。
5. 一次轻微定位解除遮挡后可截图，且只滚动一次。
6. 一次定位后仍被遮挡则封闭失败。
7. A6t 原有取价与零滚动截图契约保持通过。
8. OPPO 合法“无”、恢复、80% 缩放生命周期保持通过。
9. 荣耀、小米、京东、天猫及核心流水线代表性回归保持通过。

## 7. 验收标准

- A5m 不再因二维码遮挡已经选中的容量而在取价前失败；
- A5m 正式截图中标题、价格、颜色、容量均可人工辨认，二维码不覆盖关键内容；
- 截图定位最多发生一次，不出现上下反复滚动；
- A6t 继续成功；
- 新 Mac 测试包使用独立 `.68` 目录，不覆盖 `.67`。
