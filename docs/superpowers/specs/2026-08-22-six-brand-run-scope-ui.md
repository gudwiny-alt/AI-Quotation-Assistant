# 六品牌全站运行范围与紧凑界面设计

## 目标

在已验收的 `.118` 版本上，只调整桌面界面和运行范围，不改动荣耀、小米、OPPO、vivo、华为、苹果六个品牌已经验收通过的官网适配、取价、截图及 Excel 写入逻辑。

## 界面

- 默认窗口调整为约 `900×620`，保留人工拉伸能力。
- 运行结果文本区域由 13 行压缩为 8 行。
- 报价年份保持文本输入。
- 报价月份改为只读下拉框，值严格为 `1` 至 `12`，默认本自然月。
- 运行范围改为只读下拉框，按以下顺序展示并默认选择“全品牌”：
  1. 全品牌
  2. 荣耀
  3. 小米
  4. OPPO
  5. vivo
  6. 华为
  7. 苹果

## 运行语义

- “全品牌”处理基础表中六个已支持品牌的全部记录。
- 单一品牌只输出并处理基础表中该品牌的全部记录。
- 所有被选择的品牌均执行官网、京东、天猫三个渠道。
- 内部品牌映射保持现有规范：荣耀=`HONOR`、OPPO=`欧珀`、vivo=`维沃`。
- 中兴及其他品牌不访问网站；全品牌运行时仍保留其基础关联行，在执行报告中标为“不支持品牌”，价格和截图留空。

## 回归边界

- 不修改六品牌官网、京东、天猫适配器内部行为。
- 不修改取价、截图证据及 Excel 列写入规则。
- 保留运行前权限检查、首次登录、人工继续、断点恢复和阶段性 Excel 发布能力。
