# 荣耀搜索页面跳转与就绪校验设计

## 目标

修复荣耀官网搜索后仍停留首页、却把首页推荐商品当作搜索结果的问题；在网络较慢时，以真实页面状态而非固定延时决定何时进入卡片匹配。

## 现场证据

2026-08-01 的首页诊断显示，旧流程会把商城首页的推荐卡片误认为搜索结果。后续实测证明搜索页会将基础机型改写，例如基础表 `荣耀畅玩80` 在地址栏和搜索框中显示为 `畅玩 80`（URL 编码为 `keyword=畅玩%2080`）。逐字符比较会错误拒绝这个正确搜索页。

## 方案

1. 搜索按钮点击后，先在同一标签页等待“合法荣耀搜索 URL”：同一域名、路径 `/cn/shop/v/search`、唯一查询参数 `keyword=<基础机型>`。关键词比较忽略品牌前缀 `荣耀`/`HONOR` 与中间空白；首页 URL 即使存在 `#mainSaleList` 也不得视作结果页。
2. 在有限轮询期内未进入搜索 URL 时，按一次 Enter 作为同一搜索框的后备提交方式，再等待搜索 URL。
3. URL 就绪后，继续等待结果输入框以相同规则匹配基础机型、结果区域存在可见商品卡片。三项缺一不可。最终仍由完整商品卡片标题和荣耀数字商品链接决定是否进入详情页。
4. 每个阶段继续使用既有的 500ms 轮询与 6 秒上限；网络快时立即继续，网络慢时保持等待，超时才报告可诊断失败。
5. 详情页进入、SKU、价格、正式截图、Excel、诊断文件、窗口控制、京东和天猫均不改。

## 验收

- 首页自身有推荐卡片且点击搜索未跳转时，程序必须按 Enter，并只在进入搜索 URL 后读取结果卡片。
- 搜索 URL、关键词和结果卡片需要都就绪；慢加载期间不会提前匹配或跳转。
- 现有 Magic8 直达搜索结果与详情页回归继续通过。
