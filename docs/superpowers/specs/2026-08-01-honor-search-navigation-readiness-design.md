# 荣耀搜索页面跳转与就绪校验设计

## 目标

修复荣耀官网搜索后仍停留首页、却把首页推荐商品当作搜索结果的问题；在网络较慢时，以真实页面状态而非固定延时决定何时进入卡片匹配。

## 现场证据

2026-08-01 的两条荣耀任务均保存了诊断：搜索框中已填入 Power2 / 畅玩80，但网址仍是 `https://www.honor.com/cn/shop/?cid=132355`，页面是商城首页推荐商品。两条任务因而都以 `HONOR_PRODUCT_MATCH_MISSING` 结束。说明故障发生在搜索提交与结果页确认之间，尚未进入产品详情页。

## 方案

1. 搜索按钮点击后，先在同一标签页等待“合法荣耀搜索 URL”：同一域名、路径 `/cn/shop/v/search`、唯一查询参数 `keyword=<基础机型>`。首页 URL 即使存在 `#mainSaleList` 也不得视作结果页。
2. 在有限轮询期内未进入搜索 URL 时，按一次 Enter 作为同一搜索框的后备提交方式，再等待搜索 URL。
3. URL 就绪后，继续等待结果输入框的归一化文本与基础机型一致、结果区域存在可见商品卡片。三项缺一不可。
4. 每个阶段继续使用既有的 500ms 轮询与 6 秒上限；网络快时立即继续，网络慢时保持等待，超时才报告可诊断失败。
5. 详情页进入、SKU、价格、正式截图、Excel、诊断文件、窗口控制、京东和天猫均不改。

## 验收

- 首页自身有推荐卡片且点击搜索未跳转时，程序必须按 Enter，并只在进入搜索 URL 后读取结果卡片。
- 搜索 URL、关键词和结果卡片需要都就绪；慢加载期间不会提前匹配或跳转。
- 现有 Magic8 直达搜索结果与详情页回归继续通过。
