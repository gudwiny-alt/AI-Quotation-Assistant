# 官网与天猫已验证状态交接设计

## 背景

`.145` 是当前可回归基线，京东已有独立稳定检查点。后续现场测试显示：

- 华为官网已进入正确详情页，但价格稳定判定在观察阶段拒绝继续。
- OPPO 官网的无精确机型搜索结果已稳定同屏，但正式截图层又重新执行整个业务识别，导致语义复核失败。
- 天猫华为、荣耀已选中正确配置，但动态促销价节点可以产生多个有效数值，导致通用的“最高值连续稳定”规则拒绝截图。
- 天猫苹果在选择颜色和容量之前，被详情页卖家标签的缺失或简称拦截。

问题的共性是：观察阶段已经确定的业务事实，在截图阶段被另一套完整发现逻辑重新计算。页面内部的 React 重渲染、促销数字和标签简称虽未改变用户看到的机型、颜色、容量和价格，却会使第二套判定失败。

## 目标

1. 把“发现并验证业务事实”与“截图前确认事实未变”分离。
2. 截图前只复核已锁定证据，不再重跑完整搜索、价格发现或稳定过程。
3. 解决华为官网、OPPO 官网、天猫华为、天猫荣耀和天猫苹果的现场失败。
4. 冻结京东，不改动已验收的京东适配。
5. 保留天猫小米、OPPO、vivo 已通过行为，不为失败品牌引入全站无条件放行。

## 非目标

- 不修改京东模块、京东截图逻辑或京东浏览器调度。
- 不改变 Excel 输出、价格政策的业务定义或其他官网适配。
- 不通过“页面看起来像”的宽泛视觉判断代替结构化证据。
- 不允许天猫苹果从未经批准的店铺直接进入详情页并报价。

## 方案

### 1. 已验证状态交接

观察阶段产生的 `VerifiedSemanticState` 是一次任务的权威业务结果，包含批准 URL、品牌、机型、颜色、容量、当前 SKU、价格和结果类型。

正式截图前的 reader 只执行快照复核：

- URL 仍是已批准页面；
- 机型标题仍匹配；
- 选中颜色和容量仍唯一且正确；
- 已锁定权威价格仍在对应节点显示；
- 无机型场景中，搜索词和结果区域仍可见且未出现精确机型。

快照复核不再执行长时间轮询，不再从所有促销数字中重新选价，也不重建整个业务状态。

### 2. 华为官网

- 在主商品详情根节点内识别权威当前价格节点，排除删除价、分期、促销说明和其他重复节点。
- 价格节点通过两次一致读取后锁定；如同一权威节点内出现冲突价格，仍失败关闭。
- 截图前核对该节点的当前数值与已验证价格，不再重跑 5 秒完整稳定循环。

### 3. OPPO 官网无精确机型

- 搜索页缩放和定位完成后，缓存搜索词节点与完整结果区域的证据矩形。
- OPPO 专用的无机型 reader 只复核批准 URL、搜索词、结果区域和“仍无精确机型”，不调用通用 `_read_business_state` 重做全页识别。
- 正式截图直接使用已缓存的证据矩形。

### 4. 天猫华为与荣耀

- 价格发现改为按证据类型确定性排序：明确的“优惠前”价格节点优先；如不存在，才使用选中 SKU 的主高亮售价节点。
- 同一证据类型内如出现多个互相冲突的金额，仍拒绝报价，防止误取。
- 稳定性绑定于“同一证据类型和节点”，而不是每次对所有动态数字重新取最大值。
- 正式截图 reader 只检查锁定价格、标题、颜色和容量，不重跑价格稳定循环。

### 5. 天猫苹果官方店来源

- 从 Apple Store 官方旗舰店的受控搜索结果中选出精确商品时，记录该批准商品 URL 的可信来源。
- 进入详情页后，如卖家标签存在且明确为其他卖家，仍立即拒绝。
- 如卖家标签缺失或使用 Apple 官方店的受限简称，且当前 URL 已有受控搜索来源证明，允许继续颜色和容量选择。
- 直接打开、恢复检查点或来源不明的苹果详情页，仍必须通过明确的店铺身份校验。

## 错误处理

- 机型、颜色、容量、URL 或锁定价格真正发生变化时，仍拒绝截图和报价。
- 只有页面内部重渲染、辅助促销数字变化或已批准卖家标签简称不影响截图。
- 新的快照复核失败信息必须指明具体变化项（URL、标题、颜色、容量或价格），不再只返回“语义复核失败”。

## 测试与验收

先增加会在 `.145` 失败的合约测试，确认红灯后再改实现：

1. 华为官网：主价格稳定、辅助节点变化时能完成观察和截图复核；主价格真正变化时仍失败。
2. OPPO 官网：无机型搜索页在缩放后不再调用全页业务重读，搜索词和结果区域变化时仍失败。
3. 天猫华为/荣耀：辅助促销价变化不阻断权威价格稳定；权威价格冲突时仍失败。
4. 天猫苹果：受控官方店搜索来源＋卖家标签缺失时会继续选择颜色和容量；明确的其他卖家仍失败。
5. 回归矩阵：天猫小米、OPPO、vivo 原有测试全部通过；京东代码与 `45d158e` 基线无差异。
6. 工程校验：定向合约测试、完整测试、Ruff、Mypy、macOS 打包及严格签名校验全部通过。

## 交付与回退

- 新测试包使用 `.148` 标识，不覆盖 `.145` 或 `.147`。
- `.145` 及京东稳定检查点保留为回退基线。
- 现场测试时按官网华为、官网 OPPO、天猫荣耀、天猫华为、天猫苹果的顺序逐站冻结。
