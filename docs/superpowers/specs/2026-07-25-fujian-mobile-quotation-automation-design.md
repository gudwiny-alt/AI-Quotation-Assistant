# 福建移动资金物流平台铺货报价自动化系统

## 需求与设计说明书

- 文档版本：V1.0
- 编制日期：2026-07-25
- 当前状态：用户已确认
- 第一版目标平台：macOS 测试版、Windows 正式版

## 1. 项目背景

福建移动终端公司每月需要向福建移动提交“资金物流平台铺货产品”报价。现有工作涉及三类数据：

1. 产品经理后续手工填写的数据。
2. 从基础表、营销商品信息查询表、BOP 资源信息表关联取得的数据。
3. 从京东、天猫及品牌官网查询价格、网址并留存整屏截图的数据。

系统需要在产品经理个人电脑上运行，尽可能自动完成数据关联、网站查询、截图、Excel 生成和异常汇总。第一阶段在 MacBook Air 上验证业务逻辑，稳定后交付主要面向 Windows 产品经理的正式版本。

## 2. 设计依据与优先级

本设计基于以下样例材料：

- `2026年8月终端供货价报价表.xlsx`
- `1.基础表.xlsx`
- `2.营销商品信息查询.xlsx`
- `3.BOP资源信息表.xlsx`
- `价格及截图说明.docx`
- `截图示例.docx`

如材料之间存在冲突，采用以下优先级：

1. 本轮需求讨论中已经明确确认的规则。
2. 本需求与设计说明书。
3. 《价格及截图说明》和《截图示例》。
4. 报价表示例中的第三行说明。

## 3. 项目目标

### 3.1 核心目标

- 一次导入三张来源表，自动生成当月正式报价表。
- 以基础表 A 列编码为基准生成全部报价行。
- 自动完成表间关联、月份滚动、判断规则和公式填写。
- 自动查询三个网站渠道的价格、网址和证明截图。
- 支持首次登录后长期复用登录状态。
- 个别产品或网站失败时继续处理其他任务。
- 支持暂停、关闭、断点恢复和只重试失败任务。
- 输出正式报价表及执行报告，便于产品经理定位问题。
- 全部业务数据、日志、截图和登录状态仅保存在本机。

### 3.2 非目标

第一版不包含：

- 7 个已确认品牌以外品牌的网站自动查询。
- 自动代替产品经理填写 K、L、M、N、P、Q。
- 云端数据处理、云端 AI、团队在线协作或服务器部署。
- 绕过网站验证码、风控或安全校验。
- 手机端或网页端版本。
- 对网站未来改版保持永久免维护。

## 4. 总体方案

采用“本地桌面程序 + 本机 Chrome/Edge 自动化”的方案。

```mermaid
flowchart LR
    A["选择报价年月和三张来源表"] --> B["自动预检查"]
    B -->|文件级错误| C["停止并提示修正"]
    B -->|通过| D["生成基础行并关联数据"]
    D --> E["填写固定值、判断值和公式"]
    E --> F["按品牌/机型组织网站任务"]
    F --> G["京东、天猫、官网查价"]
    G --> H["操作系统整屏截图"]
    H --> I["逐任务保存断点"]
    I --> J["生成报价表和执行报告"]
    J --> K["查看结果或只重试失败项目"]
```

系统划分为九个主要模块：

1. 文件导入模块。
2. 自动预检查模块。
3. 数据清洗与关联模块。
4. 报价规则与公式模块。
5. 浏览器登录状态模块。
6. 网站及品牌适配模块。
7. 整屏截图与标注模块。
8. 任务进度、断点和重试模块。
9. Excel 报价表与执行报告输出模块。

## 5. 用户操作流程

1. 产品经理打开程序。
2. 程序将报价年月默认设置为运行当天所在的自然月，用户可以修改。
3. 用户选择基础表、营销商品信息查询表、BOP 资源信息表和输出文件夹。
4. 程序自动执行预检查。
5. 预检查通过后，程序自动关联数据并开始网站任务。
6. 如果某网站要求登录或验证码，程序暂停相关网站任务并提示用户处理；完成后自动继续。
7. 用户可以查看总进度、当前品牌、当前机型和当前网站。
8. 用户可以暂停、继续或关闭程序，任务进度自动保存。
9. 任务完成后，程序生成报价表和执行报告。
10. 用户可以只重新执行技术失败的任务。

## 6. 输入文件

### 6.1 每月输入

用户仅需选择：

1. 基础表。
2. 营销商品信息查询表。
3. BOP 资源信息表。
4. 输出文件夹。

正式报价模板内置在程序中，不要求产品经理每月再选择第四张模板文件。

### 6.2 基础行生成

- 基础表 A 列每一个非空编码生成一行正式报价。
- 输出行数必须与基础表 A 列非空编码数量完全一致。
- 输出顺序必须与基础表原始顺序一致。
- 不合并重复行，不静默删除异常行。
- 数据异常时仍保留对应报价行，并在执行报告中说明。

### 6.3 安全清洗

程序允许自动处理不改变业务含义的数据问题：

- 去除字段前后空格和换行。
- 统一全角、半角字符。
- 物料编码始终按文本处理，避免科学计数法及前导零丢失。
- 统一能够明确识别的日期格式。
- 统一已经确认的品牌别名，例如 HONOR/荣耀、维沃/vivo、欧珀/OPPO。

对于一对多、多个候选值冲突等无法安全判断的情况，不擅自选值，保留行并记录异常。

## 7. Excel 数据规则

### 7.1 字段来源

| 数据类型 | 报价表列 | 处理方式 |
|---|---|---|
| 基础表直接取得 | C、I、J、AB～AG | 按基础表字段及月份表头取得 |
| 营销商品信息查询表取得 | A、B、D、E、H、O 等 | 通过集团一级库物料编码关联 |
| BOP 资源信息表取得 | F、G | 通过关联键匹配 |
| 产品经理手工填写 | K、L、M、N、P、Q | 生成时保留为空 |
| 自动判断或公式 | R～AA、AH | 程序写入值或 Excel 公式 |
| 网站价格 | AI、AJ、AK | 京东、天猫、品牌官网 |
| 网站截图 | AL、AM、AN | 京东、天猫、品牌官网 |

核心关联链路：

- 基础表 A 列写入报价表 C 列“集团一级库物料编码”。
- 报价表 C 列与营销商品信息查询表 I 列匹配。
- 报价表 C 列与 BOP 资源信息表 K 列匹配。
- 营销商品信息查询表为网站查询提供品牌（C 列）、市场通俗名称（E 列）、运行内存（AQ 列）、存储容量（AR 列）和颜色（AS 列）。

关联时先将编码规范化为文本并进行精确匹配。匹配不到、匹配多条或关键字段相互冲突时，按照行级异常处理，不进行模糊猜测。

精确字段映射：

| 报价表列 | 来源 |
|---|---|
| A | 营销商品信息查询表 M |
| B | 营销商品信息查询表 C |
| C | 基础表 A |
| D | 营销商品信息查询表 B |
| E | 营销商品信息查询表 E |
| F | BOP 资源信息表 Z；未匹配填“申请配置” |
| G | BOP 资源信息表 Y；未匹配填“申请配置” |
| H | 营销商品信息查询表 V |
| I | 基础表中与报价月份往前 5 个月表头对应的列 |
| J | 基础表中与报价月份上一个月表头对应的列 |
| O | 营销商品信息查询表 X |
| AB | 基础表 I |
| AC | 基础表 J |
| AD | 基础表 K |
| AE | 基础表 L |
| AF | 基础表 M |
| AG | 基础表 B |

### 7.2 BOP 未匹配规则

BOP 资源信息表无法匹配时不视为异常中断，F、G 按既定规则填写“申请配置”，并继续执行该产品的其他处理。

### 7.3 手工字段

K、L、M、N、P、Q 在系统生成的报价表中保持空白，由产品经理后续填写。

N 列设置下拉选项：

- 货源充足
- 货源紧缺
- 新品上市
- 尾货期

手工字段为空属于预期状态，不计为程序处理失败，也不计入异常人工补充数量。

## 8. 月份滚动规则

报价年月默认等于程序运行当天所在的自然月，可由用户修改。

以 2026 年 8 月报价为例：

- I 列对应 2026 年 3 月，即报价月份往前推 5 个自然月。
- J 列对应 2026 年 7 月，即报价月份的上一个自然月。
- K 列对应 2026 年 8 月，即本次报价月份。

程序根据来源表的月份表头查找 I、J 所需数据，不依赖固定列号。缺少必要历史月份属于文件级严重错误，预检查停止并提示缺少的具体月份。

报价表第一行表头的年份和月份随所选报价年月滚动，其余文字、格式和布局保持模板一致。

## 9. 判断和公式规则

### 9.1 V 列“是否新增”

- 当 `J="无"` 或 `F="申请配置"` 时，填写“是”。
- 其他情况填写“否”。

### 9.2 W 列“达到六个月需要调价”

- 当 I 列为“无”时，填写“否”。
- 其他情况填写“是”。

### 9.3 X、Y、Z、AA

这些列写入带空值保护的 Excel 公式，以便产品经理补充手工字段后自动计算：

- X：K 为空时显示空白；J 为“无”时显示“无”；否则计算 `(K-J)/J`，显示两位小数百分比。
- Y：K 为空时显示空白；I 为“无”时显示“无”；否则计算 `(K-I)/I`，显示两位小数百分比。
- Z：K 或 L 为空时显示空白；否则计算 `(K-L)/L`，显示两位小数百分比。
- AA：K 为空时显示空白；否则计算 `K-5`。

### 9.4 R、S、T、U、AH

- AH 取 AI、AJ、AK 中的最低有效价格。
- R 等于 AH。
- S 填写最低价格对应的网址。
- 当最低价并列时，固定优先级为：AI 京东、AJ 天猫、AK 官网。
- 当 AI、AJ、AK 均为“无”时，AH、R、S 均填写“无”。
- T、U 固定填写“无”。

## 10. 正式报价表格式

输出文件名：

`YYYY年MM月终端供货价报价表.xlsx`

要求：

- 只保留“5G手机”工作表。
- 不保留示例文件中的其他可见、隐藏或深度隐藏工作表。
- 删除示例数据行和第三行说明。
- 第一行作为固定表头，只动态修改年份和月份。
- 数据行从第二行开始。
- 复制示例行的字体、字号、填充色、边框、对齐、自动换行、数字格式和数据验证。
- 保持列宽、行高、冻结窗格、打印区域、页面方向及打印设置一致。
- 截图使用标准 Excel 内嵌图片，不使用 WPS `_xlfn.DISPIMG` 或其他专属图片公式。
- 图片保持宽高比，在对应单元格内居中且不拉伸变形。
- 生成结果需要同时兼容 Microsoft Excel 和 WPS。

同名输出文件已经存在时不直接覆盖，程序保留原文件并为新结果增加执行时间标识。

### 11.3 查询步骤

1. 根据品牌进入对应指定店铺或官网。
2. 使用市场通俗名称搜索目标机型。
3. 验证完全匹配机型，不能把相似或相关商品当成目标机型。
4. 选择目标运行内存和存储容量。
5. 选择目标颜色。
6. 按渠道及品牌规则读取价格。
7. 记录结果价格和真实页面网址。
8. 生成规定状态的整屏截图。

目标容量或颜色不可选时，不采用其他配置价格代替。

### 11.4 价格选取

- 京东、天猫出现多个符合条件的价格时，取最高有效价格。
- 小米官网读取说明中指定的红色销售价格。
- HONOR、华为、维沃、欧珀、ZTE 中兴官网取符合配置的最低有效价格。
- 苹果官网取符合配置的最高有效价格。
- 不采用优惠券、以旧换新补贴、分期月供或非目标配置价格。

### 11.5 合法“无”

以下结果填写“无”，但属于正常业务成功：

- 未找到目标机型。
- 找到机型但目标容量缺失、灰色或不可选。
- 目标容量可选但目标颜色缺失、灰色或不可选。
- 商品明确下架或无货。

合法“无”必须配有符合要求的证明截图。

### 11.6 技术失败

以下属于技术失败：

- 网络中断或页面持续加载失败。
- 登录状态失效。
- 验证码或网站风控未处理。
- 页面结构变化导致无法识别。
- 来源数据缺少完成查询所需的机型、容量或颜色。
- 截图为空白、黑屏或被无关窗口遮挡。

技术失败自动重试；仍失败时保留该行，记录原因，并允许后续单独重试。

## 12. 登录状态复用

程序为自动化任务建立独立浏览器用户目录：

- 首次查询优先尝试游客访问。
- 网站要求登录时，提示用户在程序打开的浏览器中手工登录。
- 程序不读取、不保存账号和密码。
- 登录完成后自动恢复相关任务。
- Cookie 和登录状态仅保存在本机。
- 后续月份复用登录状态。
- 只有登录过期、网站强制验证或更换电脑时才重新登录。
- 某网站等待登录时，不受影响的其他任务可以继续。

程序不绕过验证码或安全校验。

## 13. 批量任务与性能策略

预计每月有 200～300 行报价，对应约 600～900 个网站任务和截图。

处理策略：

- 按品牌、机型和配置组织任务顺序。
- 同一机型先搜索一次，再依次检查不同容量和颜色。
- 同一次任务中完全相同的品牌、渠道、机型、容量、颜色可以复用查询结果。
- 不跨月份复用历史价格。
- 查询间加入合理间隔，降低触发网站风控的概率。
- 技术失败默认自动重试两次。
- 每完成一个网站任务立即保存进度。
- 支持长时间无人值守运行。

系统不承诺固定完成时长，实际时间由网站响应、登录状态、风控及产品配置数量决定。

## 14. 截图设计

### 14.1 截图方式

必须调用操作系统进行整屏截图，不使用只截取网页内容的浏览器截图。

Windows 正式版截图必须包含：

- 浏览器标签栏。
- 地址栏及真实网址。
- 网页可视区域。
- 查询结果、目标配置及价格。
- Windows 任务栏。
- 系统日期和时间。

浏览器使用最大化窗口，不进入会隐藏标签栏和地址栏的全屏模式。

Mac 测试版采用等效标准：

- 浏览器标签栏和地址栏。
- 网页可视区域。
- macOS 菜单栏及日期时间。
- Dock。

Mac 首次运行需要用户授予“屏幕录制”权限。

### 14.2 四种业务截图状态

#### 正常在售

- 显示正确机型。
- 显示目标容量和颜色已经选中。
- 显示最终采用的价格。
- 不添加红框。

#### 未找到目标机型

- 显示搜索关键词和搜索结果。
- 允许画面中存在相似或无关商品，用于证明没有完全匹配结果。
- 红框标出搜索关键词和结果区域。
- 价格填写“无”。

#### 目标容量不可选

- 显示正确机型页面。
- 显示目标容量缺失、灰色或不可选。
- 红框标出目标容量区域。
- 价格填写“无”。

#### 目标颜色不可选

- 显示正确机型和已选目标容量。
- 显示目标颜色缺失、灰色或不可选。
- 红框标出目标颜色；必要时同时标注容量区域。
- 价格填写“无”。

红框根据网页元素在屏幕中的实际位置自动绘制。

### 14.3 截图质量

- 保留足以看清网址、机型、配置、价格和系统时间的清晰度。
- 保持原始宽高比。
- 在不影响证据可读性的前提下压缩图片。
- 截图后检查空白、黑屏、遮挡和页面未稳定等问题。
- 质量不合格时自动重新截图。

整屏截图要求浏览器位于前台，因此无人值守期间不建议人工操作鼠标、键盘或切换窗口。

合法“无”的截图嵌入报价表。技术失败的异常画面仅作为本地诊断材料，不冒充业务证明；正式报价表相应截图位置暂时留空。

## 15. 自动预检查

### 15.1 文件级严重错误

以下情况停止任务：

- 文件无法读取、损坏、加密或类型错误。
- 用户选错来源表。
- 必要工作表、表头或关键列缺失。
- 基础表缺少一级库物料编码列。
- 缺少报价所需的历史月份。

程序明确显示错误文件、错误位置和建议修正方式。修正后可以重新执行。

### 15.2 行级问题

以下问题不停止整批任务：

- 营销商品信息查询表匹配不到编码。
- 品牌、机型、容量或颜色缺失。
- 同一编码存在冲突数据。
- 品牌不在第一版支持范围。
- 单个网站查询失败。
- 单个网站等待登录或验证码。

程序保留对应报价行，完成其他可处理部分并写入报告。

## 16. 任务状态、断点和恢复

每完成一个网站任务，保存：

- 任务标识和报价年月。
- 三张输入文件的识别信息。
- 当前处理位置。
- 已关联的数据。
- 已取得的价格和网址。
- 已生成的截图。
- 各步骤成功、合法“无”、失败和待重试状态。
- 浏览器独立用户目录位置。

程序关闭、电脑重启或网络中断后，可选择：

- 继续上次未完成任务。
- 只重试技术失败任务。
- 打开已有结果。
- 创建全新报价任务。

重试不得丢失或覆盖已经成功的结果，除非用户明确选择重新查询。

## 17. 结果状态

每个产品行使用以下状态：

- **自动处理完成**：所有可自动处理字段完成，三个网站均取得价格或合格的合法“无”证明。
- **部分完成**：部分自动化步骤成功，仍有网站或字段需要重试或异常人工补充。
- **处理失败**：关键关联数据严重缺失，主要自动关联和网站查询无法完成。
- **暂不支持**：品牌不在第一版 7 个品牌范围内。

K、L、M、N、P、Q 的正常待填写状态不影响上述自动化结果判断。

## 18. 执行报告

输出文件名：

`YYYY年MM月报价执行报告.xlsx`

报告包含两个工作表。

### 18.1 运行总览

- 报价年月。
- 开始时间和结束时间。
- 总报价行数。
- 自动处理完成行数。
- 部分完成行数。
- 处理失败行数。
- 暂不支持行数。
- 异常人工补充行数。
- 按产品经理汇总。
- 按品牌汇总。
- 京东、天猫、官网各自的成功、合法“无”和技术失败数量。

### 18.2 处理明细

每个产品一行，至少包含：

- 产品经理。
- 品牌。
- 集团一级库物料编码。
- 产品名称及配置。
- 三张来源表关联状态。
- 京东、天猫、官网的价格状态和截图状态。
- 最终处理状态。
- 失败步骤。
- 失败原因。
- 建议处理方式。

报告使用绿色、橙色和红色区分完成、部分完成和失败，并开启筛选功能。

## 19. 桌面界面

界面面向非技术人员，不显示命令行。

主要区域：

1. 报价年月和文件选择。
2. 自动预检查结果。
3. 总进度及完成、部分完成、失败、剩余数量。
4. 当前品牌、机型、渠道和处理阶段。
5. 开始、暂停、继续、停止。
6. 登录或验证码提示。
7. 打开报价表、打开执行报告、只重试失败项目。

关闭程序前自动保存任务状态。

## 20. 本地安全与数据存储

以下内容仅保存在用户电脑：

- 输入表。
- 正式报价表。
- 执行报告。
- 截图和诊断画面。
- 运行日志。
- 任务断点。
- 浏览器 Cookie 和登录状态。

安全要求：

- 不使用云端 AI。
- 不上传 Excel 或截图。
- 网络连接仅用于访问目标购物网站和品牌官网。
- 不保存账号密码。
- 日志不记录 Cookie、密码或其他登录凭证。
- 任务数据和程序文件分开存放，更新程序不删除历史任务或登录状态。

## 21. 技术选型

建议第一版采用：

- Python：跨平台业务逻辑。
- 轻量桌面 GUI：提供 Mac 和 Windows 一致的操作界面。
- Playwright：控制本机 Chrome/Edge，并使用持久化浏览器用户目录。
- openpyxl：基于内置模板生成正式报价表、公式、样式和图片。
- XlsxWriter 或 openpyxl：生成执行报告。
- SQLite：保存任务状态、断点和重试信息。
- Pillow 与系统原生截图接口：截图压缩、红框标注和质量检查。
- PyInstaller：打包为无需安装 Python 的 Mac `.app` 和 Windows 便携式程序。

实施阶段需要通过样例文件验证 openpyxl 对模板格式、打印设置和图片的保真度；如果个别格式无法无损保留，采用“从精简后的正式模板复制并最小化修改”的方式处理。

## 22. 交付方式

### 22.1 Mac 测试版

- 交付可双击运行的 `.app`。
- 使用本机 Chrome。
- 首次授权屏幕录制权限。
- 用于验证数据、公式、网站查询、截图、报告和断点恢复。

### 22.2 Windows 正式版

- 交付免管理员权限的便携式程序目录。
- 解压后双击运行。
- 不要求安装 Python。
- 优先使用 Chrome；没有 Chrome 时使用 Edge。
- 严格按截图示例保留 Windows 标签栏、地址栏、任务栏和系统时间。
- 登录状态和任务数据保存到当前用户本地应用数据目录。

网站规则更新采用新的本地程序版本，不设置云端自动更新。替换程序文件时保留历史任务和浏览器登录状态。

## 23. 验收标准

### 23.1 Excel

- 基础表 A 列非空编码数量等于报价数据行数。
- 输出顺序与基础表一致。
- 三张来源表关联结果正确。
- 月份滚动正确，不依赖固定列号。
- V、W、X、Y、Z、AA、R、S、T、U、AH 规则正确。
- K、L、M、N、P、Q 为空，后续填写后公式自动计算。
- 最终只保留“5G手机”工作表。
- 表头、字体、颜色、边框、对齐、列宽、行高、冻结和打印设置符合示例。
- Excel 和 WPS 均可打开并查看标准内嵌截图。

### 23.2 网站和截图

- 7 个品牌的三个渠道能够按规则查询。
- 登录状态能够跨任务复用。
- 价格、网址及最终最低价选择正确。
- 最低价并列时采用京东、天猫、官网固定优先级。
- 正常、未找到机型、容量不可选、颜色不可选四种截图状态符合要求。
- 合法“无”和技术失败能够正确区分。
- Windows 截图严格符合示例，Mac 截图符合等效标准。

### 23.3 稳定性

- 能够执行 200～300 行的完整批次。
- 中途关闭后可以恢复。
- 网络短暂异常自动重试。
- 可以只重试失败项目。
- 部分失败时仍生成部分完成报价表和执行报告。
- 重试不破坏已成功结果。

### 23.4 安全

- 输入表、输出表、截图、日志、Cookie 和断点均留在本机。
- 不存在业务数据上传。
- 程序和日志不保存账号密码。

## 24. 测试和上线顺序

1. 使用现有样例在 Mac 完成数据关联和 Excel 生成测试。
2. 验证月份滚动、公式和异常预检查。
3. 分品牌验证京东、天猫和官网的正常查价。
4. 验证四种截图状态及合法“无”。
5. 验证登录复用、暂停、关闭、恢复和失败重试。
6. 使用较大数据集执行 200～300 行压力测试。
7. 在 Windows 电脑上验证严格截图标准。
8. 验证 Excel 与 WPS 打开效果。
9. 修正网站适配问题后封装 Windows 正式版。

## 25. 已知风险与应对

| 风险 | 影响 | 应对 |
|---|---|---|
| 网站页面改版 | 某品牌或渠道无法识别 | 品牌与网站适配器独立维护，失败明确报告 |
| 登录失效或验证码 | 相关任务暂停 | 提示人工登录，完成后自动恢复 |
| 网站风控 | 查询速度下降或暂时失败 | 分组、合理间隔、有限重试，不绕过安全机制 |
| 600～900 张整屏图导致文件较大 | Excel 打开和保存变慢 | 在证据可读前提下压缩，逐任务落盘 |
| 用户操作影响整屏截图 | 截图被遮挡 | 前台最大化、截图质量检查、失败自动重截 |
| 来源表字段或月份结构变化 | 关联或滚动失败 | 自动预检查，文件级错误在网站任务前停止 |
| 不同电脑显示比例不同 | Windows 截图布局变化 | 最大化浏览器、固定浏览器缩放并进行环境检查 |

## 26. 设计结论

第一版采用完全本地、可恢复、面向非技术人员的桌面自动化方案。系统以基础表编码为报价行基准，关联三张来源表，保留手工字段，自动生成公式，并针对 7 个品牌完成京东、天猫和官网的价格、网址及整屏证据截图。个别异常不影响整批处理，最终同时提供正式报价表和可定位问题的 Excel 执行报告。
