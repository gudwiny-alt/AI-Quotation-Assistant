# 荣耀官网详情页进入修复设计

## 目标

使荣耀官网在搜索结果页唯一识别基础表机型后，于同一标签页进入 `/cn/shop/product/<数字>.html` 详情页；只有详情页完成型号、内存和颜色校验后，后续价格与截图流程才可执行。

## 根因与范围

`荣耀Power2 12GB+256GB` 这类商品卡片在基础型号后以空格加容量开头。现有卡片匹配将容量首位数字视为“模型名粘连”，错误地拒绝了正确商品卡片，任务因而停在搜索页并对同一确定性错误重试三次。

本次仅改荣耀官网的搜索结果卡片语义匹配和该阶段错误分类。不改窗口控制、截图、Excel、已验证的详情页 SKU/价格校验，亦不改京东或天猫。

## 行为

1. 型号名必须仍是商品卡片文本的开头；无分隔的 ASCII 字母或数字仍视为不同型号并拒绝。
2. 型号名后存在空格时，允许容量、网络制式、中文官方描述等商品信息；`Pro`、`Pro+`、`Plus`、`Ultra`、`Max`、`SE` 等列明的型号变体仍拒绝。
3. 仅一个合格卡片时，取其数字商品链接并在当前标签页导航。详情页已有的精确 URL、标题、内存、颜色、库存和价格校验保持不变。
4. 零个或多个合格卡片时，记录一次不可重试的 `HONOR_PRODUCT_MATCH_MISSING` 或 `HONOR_PRODUCT_MATCH_AMBIGUOUS`。页面保留在搜索结果页，供产品经理检查；不会对相同搜索结果连续重试。

## 验收与回归

- `荣耀Power2 12GB+256GB` 卡片会进入数字详情页。
- `荣耀Magic8 Pro` 不会被基础机型 `荣耀Magic8` 误选。
- 不匹配的搜索页会在一次任务尝试后给出可读原因。
- 既有荣耀详情页、截图和 Excel 写入回归继续通过。
