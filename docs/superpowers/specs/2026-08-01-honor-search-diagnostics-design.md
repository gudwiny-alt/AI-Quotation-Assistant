# 荣耀搜索匹配诊断设计

## 目标

当荣耀官网在搜索结果页无法唯一匹配基础表机型时，自动保存足以定位匹配问题的本地证据，而不改变搜索、详情页、价格、截图或 Excel 写入行为。

## 已确认的事实

- `荣耀Magic8` 的既有闭环能够完成价格和截图。
- `荣耀Power2` 与 `荣耀畅玩80` 均在荣耀官网搜索后，以 `HONOR_PRODUCT_MATCH_MISSING` 在详情页进入之前失败。
- 因此当前故障位于“搜索结果卡片文字 → 基础机型匹配”边界，不是 Excel 写入或正式截图失败。

## 范围与行为

1. 仅当任务为 `HONOR`、渠道为官网且错误码是 `HONOR_PRODUCT_MATCH_MISSING` 或 `HONOR_PRODUCT_MATCH_AMBIGUOUS` 时，诊断回调才运行。
2. 在失败现场的同一自动化网页标签页，保存：当前搜索 URL、基础机型、最多 12 张结果卡片的可见文字与商品链接，以及当前可视搜索页 PNG 截图。
3. PNG 是任务报告可打开的诊断文件；同名 `.json` 保存结构化文字和链接，二者只保存至本次输出目录的 `evidence/diagnostics`。
4. 诊断内容不记录 Cookie、请求头、登录资料或个人 Chrome 数据。截图由浏览器页面自身生成，不读取系统桌面。
5. 诊断失败不能改变原有失败码、不能触发重试，也不能覆盖任何成功的价格或正式证据图。

## 不在本次范围

- 不修改 `HonorOfficialOverride.card_matches_model()`、详情页 SKU/价格校验、正式截图、Excel、窗口尺寸、京东或天猫。
- 不处理 macOS 屏幕录制授权；该问题与本次网页搜索匹配诊断独立处理。

## 验收

- 对 Power2 或畅玩80 的一次失败，执行报告的诊断路径指向本地 PNG，旁边存在 JSON。
- JSON 中能看到搜索 URL、输入机型、可见卡片文本和商品链接，以便据实确定下一步匹配规则。
- Magic8 成功路径和现有荣耀详情页/Excel 回归不改变。
