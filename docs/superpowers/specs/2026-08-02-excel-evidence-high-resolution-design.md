# Excel 高清截图设计

## 目标

提高报价表内 AL、AM、AN 截图在 Excel 放大查看时的可读性，同时保持既有网页取价、截图触发、逐条写入和报价表版式不变。

## 范围

仅调整正式截图写入 Excel 前的图片编码策略：

- 最大像素尺寸从 960×600 提升为 1920×1200；
- JPEG 质量优先使用 92；
- 单张图片上限从 192KB 提升为 1.5MB；
- 只有超过单张上限时才按既有高质量缩放算法逐步缩小；
- Excel 单元格内的显示大小和锚点保持不变，提升的是嵌入图片的原始像素密度。

## 不变项

- 不修改荣耀官网搜索、商品详情页进入、颜色/内存/套餐处理、价格读取和截图条件；
- 不修改 Excel 的字段、公式、表头、行高、列宽和图片锚点；
- 不修改京东、天猫或其他品牌逻辑；
- 不改变正式截图的真实性、校验和缓存规则。

## 错误处理

若一张正式截图无法在限定的最小尺寸内压缩到 1.5MB，维持现有失败语义，不写入未经验证的图片。

## 验证

- 先新增失败测试：一张高分辨率网页截图被写入 Excel 后，嵌入图像应超过旧的 960×600 限制，且 JPEG 质量不会回退为旧的低质量压缩；
- 执行现有 Web-to-Excel、报价表写入和 macOS 端到端回归；
- 重新打包 macOS 测试应用并进行签名校验。

## 预期代价

最终 Excel 文件会明显增大。按三站截图、200–300 个机型估算，文件可能达到数百 MB；这是换取表内放大可读性的明确取舍。
