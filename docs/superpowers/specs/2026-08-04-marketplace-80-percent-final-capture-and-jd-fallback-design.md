# 京东／天猫最终阶段固定 80% 与京东库存解耦设计

## 背景与实测证据

以 `.40` 测试包为基线。2026 年 8 月两条荣耀实测中：

- 荣耀官网两条价格及截图均成功，必须保持不变。
- 京东 Power2 已进入正确详情页，基础表目标配置 `12GB+256GB`、幻夜黑均可选择并可保持选中；程序却受到页面“暂时售完／到货通知”等库存文案影响，错误输出“容量不可用”，没有读取该精确配置的划线价 `2699`。
- 京东畅玩80已经正确判定“无该机型”，但搜索框与不匹配商品名称在 90% 下仍未通过同屏截图校验。
- 天猫尚未接入最终截图比例调整。

## 目标

1. 京东和天猫只在最终状态复核与正式截图阶段临时切换到 80%；搜索、登录、验证、商品卡点击和详情页进入过程保持原比例。
2. 京东精确机型详情页中，选择基础表指定的容量和颜色；只要配置控件存在、可以选择并能保持选中，就继续报价，不因整机“暂时售完／到货通知”等库存状态停止。
3. 京东 Power2 选择 `12GB+256GB`、幻夜黑后，按既有最高有效价格规则读取当前配置的已验证划线原价 `2699`，不采用补贴后价或到手价。
4. 京东畅玩80无报价截图同时显示经验证的搜索词和可读的不匹配商品名称。
5. 荣耀官网流程完全不变。

## 方案选择

采用“最终阶段临时 80% + 精确配置选择与库存状态解耦”方案。

未采用的方案：

- 全查询过程保持 80%：会扩大对登录、风控、搜索输入和页面跳转的影响范围。
- 继续把页面整体售罄写成“容量不可用”：与本次 Power2 人工确认的报价规则冲突，也会漏掉页面明确展示的 `2699` 划线价。

## 京东处理规则

### 精确机型与配置

1. 搜索结果仍必须精确匹配当前机型；不得从 Power、Power2 或其他相近型号之间串价。
2. 进入正确详情页后，先尝试基础表指定容量与颜色。
3. 配置是否有效只看配置控件本身：存在、能够点击或已经选中，并能在页面更新后保持选中。
4. 页面整体显示“暂时售完”“到货通知”，或者其他颜色显示“无货”，均不得让已经可选的目标容量和目标颜色变成“容量不可用／颜色不可用”。
5. 不回退到其他容量或颜色；目标配置控件确实不存在或不能选中时，才输出对应的配置不可用状态。
6. 记录并复核实际选中的精确容量、颜色和 SKU，截图必须展示该配置。

### 价格

1. 价格必须绑定当前精确配置所选中的 SKU。
2. 延续京东 `HIGHEST` 价格策略。
3. 当前配置同时显示补贴后价与有效划线原价时，划线原价属于可验证报价候选；Power2 `12GB+256GB`、幻夜黑应取得 `2699`。
4. 优惠券、分期金额、以旧换新金额及无法绑定当前 SKU 的数字继续排除。

### 无机型截图

1. 正确判定无精确机型后进入最终截图阶段。
2. 应用 80% 临时比例并等待页面重排。
3. 定位首个可见商品卡，使搜索框中的当前搜索词与至少一个不匹配商品名称同屏。
4. 条件满足后立即截图，不再执行第二次滚动。

### 详情页截图

1. 价格和实际配置验证完成后应用 80% 临时比例。
2. 只定位一次，使产品标题、有效价格、实际选中颜色和实际选中容量同屏。
3. 条件满足后立即截图；截图结束、失败或取消后恢复原比例。

## 天猫处理规则

1. 不修改天猫登录、搜索、商品匹配、配置选择或价格读取规则。
2. 仅在最终状态复核与截图阶段应用 80% 临时比例。
3. 详情页要求标题、价格、颜色和容量同屏；无机型页要求搜索词与商品名称同屏。
4. 截图结束、失败或取消后恢复原比例。

## 状态与恢复

- 站点适配器保存应用 80% 前的网页比例。
- 正式截图运行器在成功、失败和异常路径均调用恢复钩子。
- JD 语义检查点保存精确容量、颜色和 SKU；后续复核只确认配置仍被选中，不得因页面整体库存文案重新判定失败。

## 自动测试

- JD 最终截图固定应用 80%，不再应用 90%。
- JD 无机型结果页在 80% 下同时校验搜索框和商品名称。
- JD 精确容量可用时仍使用原有精确配置逻辑。
- JD 精确目标配置可选择但整机暂时售完时，仍读取该配置划线价 `2699`。
- JD 目标配置控件确实不存在或不能保持选中时，仍输出配置不可用，不回退其他配置。
- JD 不得从其他机型或不可验证价格节点取价。
- Tmall 的有报价与无机型截图均应用 80%，并在结束后恢复。
- 荣耀官网回归结果保持不变。

## 人工验收

1. Power2 京东列写入 `2699`，截图可见 Power2 标题、`2699`、幻夜黑和 `12GB+256GB`。
2. 畅玩80京东价格为“无”，截图可见搜索框中的畅玩80搜索词及下方不匹配商品名称。
3. 天猫最终截图画面在 80% 下包含对应必需信息。
4. 荣耀官网价格与截图和 `.40` 保持一致。
