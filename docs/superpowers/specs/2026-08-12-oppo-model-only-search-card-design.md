# OPPO 官网按机型进入任意商品卡设计

## 背景

`.62` 已能打开 OPPO 官网真实搜索弹层并提交关键词，但 A5m 与 A6t 在搜索结果页没有基础表指定颜色时，未进入商品详情页。搜索结果页只是进入同一机型详情页的入口；目标容量和颜色应在详情页配置区选择，不应成为搜索卡片的前置门槛。

## 目标

- 搜索结果阶段只精确匹配基础机型。
- 同一机型存在多张商品卡时，选择第一张具有合法 OPPO 官方详情链接的可见卡片。
- 搜索结果阶段不校验容量、颜色或库存。
- 进入详情页后，严格选择基础表目标容量和颜色，再取价并截图。
- 仅修改 OPPO 官网适配器，不触碰荣耀、小米、京东、天猫、Excel 或其他品牌。

## 精确机型边界

允许：

- `OPPO A5m 5G` 匹配官网卡片 `OPPO A5m 水晶粉 ...`；官网省略输入中的网络标记时仍视为同一基础机型。
- `OPPO A6t` 匹配 `OPPO A6t 青出于蓝 ...`。

拒绝：

- `OPPO A5m Pro`、`OPPO A5x` 等相近但不同机型。
- `OPPO A6 Pro`、`OPPO A6i`、`OPPO A6k`、`OPPO A6m` 等相近但不同机型。
- 非 OPPO 官方数字商品详情路径。

## 数据流

1. 打开 OPPO 商城并打开真实全屏搜索弹层。
2. 输入基础表机型并提交搜索。
3. 等待搜索结果区域稳定。
4. 读取每张可见商品卡自身的标题和详情链接。
5. 过滤出精确基础机型及合法 OPPO 官方详情链接。
6. 按页面显示顺序进入第一张合法精确机型卡；忽略该卡当前显示的容量、颜色和库存。
7. 在详情页选择目标容量，再选择目标颜色。
8. 读取稳定官网价格。
9. 截图只要求产品名称、官网价格、目标容量、目标颜色四项同屏。

## 缩放与截图

- 复用小米已验证的四项同屏经验。
- 进入详情页后先判断产品名称、价格、容量、颜色能否同屏。
- 若当前视图已经满足四项同屏，直接截图，不滚动、不重复缩放。
- 若当前视图不足，单次切换到稳定的 80% 视图，再重新判断四项。
- 只有 80% 后仍不能同屏时，才允许一次定向定位；不得反复上下滚动或反复缩放。
- 截图校验不增加库存、收货地区、套餐或其他业务条件。

## 异常处理

- 搜索结果中没有精确基础机型：完成稳定等待后写入合法“无机型”及搜索证据。
- 详情页没有目标容量：写入合法“无容量”证据。
- 详情页没有目标颜色：写入合法“无颜色”证据。
- 有精确机型卡但链接不合法、点击后不是同机型详情页或页面结构无法证明四项：技术失败，不误写“无”。
- 缺货商品卡仍可进入详情页；库存不参与卡片筛选或截图判断。

## 测试设计

必须先新增失败测试，再修改生产代码：

1. A5m 搜索结果只有水晶粉卡，仍进入详情页并选择钻石白、8GB+256GB。
2. A6t 搜索结果只有青出于蓝卡，仍进入详情页并选择墨竹黑、6GB+128GB。
3. 同屏存在 A6t、A6 Pro、A6i 时，只进入 A6t。
4. 搜索卡容量和目标容量不同，仍进入详情页并在那里选择目标容量。
5. 缺货的精确机型卡仍可进入详情页。
6. 四项在当前视图已齐全时不缩放、不滚动；不足时只应用一次 80% 缩放，并保持小米、荣耀冻结回归通过。

## 验收标准

- A5m、A6t 均能从搜索结果进入正确详情页。
- 在详情页成功选择基础表目标容量和颜色。
- 价格写入 `AK`，截图写入 `AN`。
- 多行按基础表顺序逐条处理。
- OPPO 契约、管线集成、品牌隔离以及荣耀/小米冻结回归全部通过。
- Mac 实机验收通过后冻结 OPPO，再进入 vivo 开发。
