# Bundled brand marks

Huawei, OPPO, vivo, HONOR, Xiaomi, Apple: Simple Icons 14.9.0 SVGs (CC0-1.0); see LICENSE.md and sources.json for brand source URLs. Marks remain the property of their owners and identify sources only.
https://github.com/simple-icons/simple-icons/tree/14.9.0

JD and Tmall: high-resolution marks published by their official App Store developers; see channel-sources.json. Retrieved 2026-09-10. The earlier .ico files are retained as source provenance only; the application loads the PNG files.
Chrome: https://www.google.com/chrome/static/images/chrome-logo.svg (retrieved 2026-09-09).

PNG derivatives are rendered at build time; no runtime download. Manufacturer marks are chosen from the product name; unknown official sources use the generic globe icon. Generic phone artwork is stored separately in ui-media and is not evidence or a model-specific photograph.
