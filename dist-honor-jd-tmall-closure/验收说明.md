# 荣耀闭环验收包

版本：`荣耀逐条保存·官网京东天猫闭环版（全部荣耀行）2026.07.30.1`

验收时请选择“仅 HONOR”。程序会按以下顺序执行：

1. 官网全量：完成基础表中全部荣耀行的官网价格与截图；
2. 京东全量：完成全部荣耀行的京东价格与截图；
3. 天猫全量：完成全部荣耀行的天猫价格与截图。

本版逐条保存：价格确认后立即写入“处理中”Excel，截图成功后立即补图。
运行期间请从输出目录打开文件名含“处理中”的报价表和执行报告，检查已完成阶段。

如京东或天猫出现登录、验证码或安全验证，程序会停留在当前任务和当前页面。
人工处理完成后，点击程序中的“继续当前任务”，程序会从暂停任务继续并保留已保存阶段结果。
Mac 测试版仍沿用已确认的人工摆放窗口方案：浏览器出现后摆好一次即可，
程序不会在后续渠道中主动缩放窗口。

重点检查：

- 输出表仅包含基础表中的全部荣耀行，顺序不变；
- 每行的自动关联字段和公式完整；
- `AI/AL` 为京东价格/截图；
- `AJ/AM` 为天猫价格/截图；
- `AK/AN` 为荣耀官网价格/截图；
- “无该机型、容量不可用、颜色不可用、售罄”等合法“无”仍带证明截图；
- 执行报告中的总行数、完成/失败数和荣耀产品明细与输出表一致。

本包使用程序专用的持久化 Chrome 目录；已登录状态会在同一台电脑上复用。
